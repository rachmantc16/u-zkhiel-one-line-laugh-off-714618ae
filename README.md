A tiny Node program that writes one single-line joke (200 characters or fewer) to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that environment variable is set. The line is written with no trailing newline, so the file contains exactly the joke and nothing else: a will reading where Grandpa leaves his family no house and no money, only one chair, a referee's whistle, and a note wishing the best grandchild victory.

## Run it

```sh
node main.ts
```
